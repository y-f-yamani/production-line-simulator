Process and resource settings stacked rows · changes apply immediately⌄
  • Cycle time formula: max(Manual work ÷ assigned operators, Machine time ÷ assigned automatic machines). The larger result sets the cycle. A 0-second workload counts as 0; a required workload with no assigned resource stops the process.
  • Batch / Chamber: capacity uses processing percentage, batch duration, items per batch, batch-equipment count, and start schedule. Use 100% for mandatory testing; use a lower percentage only for sampling.
  • Transfer time: covers movement and handling between processes.
  • Busy time: line throughput ÷ process capacity.
